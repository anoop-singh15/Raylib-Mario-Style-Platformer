## 📖 About The Project

Raylib Mario-Style Platformer is a 2D platformer game inspired by the classic Mario series.

Developed using **C++** and the **Raylib 5.5** graphics library, this project focuses on implementing fundamental game development concepts while creating an enjoyable platforming experience.

## ✨ Features

- 🎮 2D Mario-inspired platforming gameplay
- 🏃 Player movement mechanics
- ⬆️ Jumping mechanics
- 👾 Enemy interactions
- 🧱 Collision detection
- 🎨 Texture-based graphics using Raylib

## 💻 Getting Started

Follow these instructions to set up and run the project on Windows.

### 📌 Prerequisites

Make sure you have installed:

- Windows 10 / 11
- [Visual Studio Code](https://code.visualstudio.com/)
- [Raylib 5.5](https://www.raylib.com/)
- Prebuilt Raylib VS Code configuration for Windows

### ⚙️ Installation

**1. Install Raylib 5.5**

Download Raylib 5.5 from the [official website](https://www.raylib.com/) and install or extract it into your `C:\` drive.

**2. Clone the Repository**

Open Command Prompt or the VS Code terminal and run:

```bash
git clone https://github.com/anoop-singh15/Raylib-Mario-Style-Platformer.git
```

**3. Open the Project**

- Navigate to the downloaded repository folder.
- Double-click `main.code-workspace`.
- The project will open in Visual Studio Code.

**4. Open the Main Source File**

Navigate to the `src` folder and open `main.cpp`.

**5. Build and Run**

Press the following shortcut in VS Code:

```text
Ctrl + F5
```

The game should compile and launch.
