# Raylib-Mario-Style-Platformer
A 2D Mario-inspired platformer game developed in C++ using the Raylib library, featuring classic platforming mechanics, player movement, jumping, and enemy interactions.
💻 How to Run This Project on Windows
Prerequisites
Before running the project, make sure you have:

Windows 10/11
Visual Studio Code
Raylib 5.5
Prebuilt Raylib VS Code configuration for Windows
Setup Instructions
1. Install Raylib 5.5

Download Raylib 5.5 and install or extract it into your C: drive.

2. Set Up Raylib VS Code Configuration

Download the prebuilt Raylib VS Code configuration for Windows and follow its setup instructions.

Make sure Raylib is properly configured with Visual Studio Code.

3. Clone This Repository


bash
git clone https://github.com/YOUR-USERNAME/mario-platformer-cpp.git
4. Open the Project in VS Code

Navigate to the downloaded project folder.
Double-click the main.code-workspace file.
This will open the project in Visual Studio Code.
5. Open the Main Source File

From the VS Code Explorer:

Navigate to the src folder.
Open main.cpp.
6. Build and Run the Game

Press F5 on your keyboard to compile and run the game.
