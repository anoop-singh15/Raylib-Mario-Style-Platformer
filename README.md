🎮 Raylib Mario-Style Platformer

A 2D Mario-inspired platformer game developed using C++ and the Raylib 5.5 library, featuring classic platforming mechanics, player movement, jumping, and enemy interactions.

🛠️ Technologies Used
Language: C++
Graphics Library: Raylib 5.5
Code Editor: Visual Studio Code
Platform: Windows
💻 How to Run This Project on Windows
📌 Prerequisites

Before running the project, make sure you have installed:

Windows 10 / 11
Visual Studio Code
Raylib 5.5
Prebuilt Raylib VS Code configuration for Windows
⚙️ Setup Instructions
1. Install Raylib 5.5

Download Raylib 5.5 from the official website and install or extract it into your C: drive.

2. Clone This Repository

Open Command Prompt or the VS Code terminal and run:

bash
git clone https://github.com/anoop-singh15/Raylib-Mario-Style-Platformer.git

3. Open the Project in VS Code
Navigate to the downloaded project folder.
Double-click the main.code-workspace file.
The project will open in Visual Studio Code.
4. Open the Main Source File
Navigate to the src folder in the VS Code Explorer.
Open main.cpp.
5. Build and Run the Game

Press Ctrl + F5 on your keyboard to compile and run the game.

Enjoy playing! 🎉

🎮 Controls
Key	Action
A / ←	Move Left
D / →	Move Right
Spacebar	Jump
